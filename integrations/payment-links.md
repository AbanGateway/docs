# لینک پرداخت

اگر سایتی ندارید یا نمی‌خواهید چیزی برنامه‌نویسی کنید، لینک پرداخت همان کار را می‌کند: یک آدرس می‌سازید و برای خریدار می‌فرستید.

## ساختنش

از هر دو جا:

- **سایت** — پنل ← لینک‌های پرداخت ← لینک جدید
- **ربات تلگرام** — «لینک پرداخت»

اپلیکیشن اندروید لینک پرداخت نمی‌سازد؛ کارش رساندن پیامک بانک و شارژ کیف پول است.

## دو نوع

**مبلغ ثابت.** عدد را خودتان می‌گذارید. برای یک محصول مشخص، یا یک قسط.

**مبلغ باز.** خریدار مبلغ را می‌نویسد. برای پرداخت آزاد، یا وقتی مبلغ هر بار فرق می‌کند.

## چند بار قابل استفاده؟

هر بار که کسی لینک را باز کند یک فاکتور تازه ساخته می‌شود، با مبلغ متمایز خودش. یعنی یک لینک را می‌شود به ده نفر داد و هر ده پرداخت جدا تشخیص داده می‌شوند.

اگر می‌خواهید لینک فقط یک بار کار کند، موقع ساختش یک‌بارمصرف علامتش بزنید.

## کارمزد

مثل هر فاکتور دیگری، از کیف پول کارمزد. [جدولش](../guides/fees.md).

## فرقش با API چیست

هیچ، از دید خریدار. از دید شما، لینک پرداخت چیزی است که خودتان دستی می‌سازید و می‌فرستید؛ API همان کار را خودکار می‌کند و وبهوک هم می‌دهد تا سفارش خودش تحویل شود.

اگر فروشگاه اینترنتی دارید، API یا [افزونه‌ی ووکامرس](woocommerce.md) را بخواهید. لینک پرداخت برای فروش در اینستاگرام، تلگرام و پیام مستقیم است.
