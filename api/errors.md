# خطاها

هر خطا یک بدنه‌ی یکسان دارد:

```json
{
  "error": {
    "code": "insufficient_fee_wallet",
    "message": "Fee wallet balance is not enough to open this invoice",
    "details": { "required_rial": 40000, "available_rial": 12000 }
  }
}
```

`details` همیشه نیست؛ وقتی هست عددی است که کمکتان می‌کند تصمیم بگیرید.

روی `code` شرط بگذارید نه روی `message`. متن پیام ممکن است بهتر نوشته شود؛ کد عوض نمی‌شود.

## فهرست

<div dir="rtl">

| HTTP | کد | معنی |
|---|---|---|
| `402` | `insufficient_fee_wallet` | موجودی کیف پول کارمزد کافی نیست |
| `402` | `not_yet_paid` | هنوز پرداختی برای این فاکتور ثبت نشده |
| `403` | `sandbox_only` | این عملیات فقط با توکن تست کار می‌کند |
| `404` | `invoice_not_found` | فاکتوری با این شناسه نیست |
| `409` | `already_verified` | این فاکتور قبلاً تأیید شده |
| `409` | `cards_at_ceiling` | همه‌ی کارت‌ها به سقف دوره‌شان رسیده‌اند |
| `409` | `invoice_not_payable` | فاکتور دیگر باز نیست |
| `409` | `no_card_registered` | قبل از ساخت فاکتور یک کارت ثبت کنید |
| `410` | `invoice_expired` | فاکتور پیش از پرداخت منقضی شد |
| `422` | `invalid_request` | بدنه درخواست ناقص یا نادرست است؛ `details.fields` میگوید کدام فیلد و چرا |
| `422` | `amount_not_allowed` | مبلغ خارج از بازه‌ی مجاز است |
| `422` | `unsafe_callback_url` | آدرس بازگشت از اینترنت عمومی در دسترس نیست |
| `503` | `capacity_full` | فعلاً هیچ مبلغ متمایزی روی این کارت آزاد نیست |

</div>

بدون توکن یا با توکن نامعتبر `401` می‌گیرید با بدنه‌ی `{"detail": "..."}`. عبور از محدودیت نرخ `429` است با هدر `Retry-After`.

## آنهایی که واقعاً پیش می‌آیند

**`insufficient_fee_wallet`** — شایع‌ترین. کارمزد از کیف پول جدا کم می‌شود و موقع **ساخت** فاکتور رزرو می‌شود، نه موقع پرداخت. کیف پول که خالی شود، فاکتور جدید ساخته نمی‌شود. `details` می‌گوید چقدر کم دارید.

**`already_verified`** — این خطا نیست. یعنی سفارش قبلاً تحویل شده. مثل موفقیت رفتارش کنید، وگرنه یک وبهوکِ دوباره‌فرستاده‌شده باعث می‌شود مشتری پیام خطا ببیند.

**`capacity_full`** — هر فاکتورِ باز یک مبلغ منحصربه‌فرد روی یک کارت رزرو می‌کند، و آن مبلغ‌ها بی‌نهایت نیستند. اگر به این خوردید یعنی همزمان بیش از حد فاکتور باز دارید: یا کارت دیگری اضافه کنید، یا مهلت فاکتورها را کوتاه‌تر کنید تا زودتر آزاد شوند.

**`invalid_request`** — معمولا در اولین اتصال. نام فیلدها با درگاه های دیگر فرق دارد: مبلغ `amount_rial` است و به ریال. پیام خطا نام فیلد را میگوید و `details.fields` همه فیلدهای مشکل دار را با نوع مشکل (`missing`، `int_parsing` و مانند آن) فهرست میکند.

**`unsafe_callback_url`** — آدرس باید HTTPS و از اینترنت عمومی قابل دسترس باشد. `localhost`، آی‌پی داخلی و HTTP ساده رد می‌شوند. برای توسعه‌ی محلی از یک تونل استفاده کنید.
